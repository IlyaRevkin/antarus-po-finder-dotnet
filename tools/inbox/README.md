# Ящик агента на cloud.rev-il.ru

Тикеты и реквизиты RustDesk больше не лежат в репозитории. Илья кладёт их в свой Nextcloud
(`cloud.rev-il.ru`, версия 32), агент забирает оттуда по WebDAV. Причин две: секретам не место в
публичной истории Git, а скриншот в облако кидается мышью, в отличие от коммита.

Отдельную страницу для загрузки писать не понадобилось — веб-интерфейс Nextcloud ей и является.

## Что сделать Илье — один раз, минуты три

1. **Завести пароль приложения.** В Nextcloud: аватар справа сверху → «Личные настройки» →
   «Безопасность» → внизу «Устройства и сеансы» → в поле имени написать `antarus-agent` →
   «Создать новый пароль приложения». Пароль показывается **один раз** — скопировать сразу.
   Это не пароль от входа: он не даёт зайти в веб-интерфейс и отзывается одной кнопкой там же.

2. **Положить его в `.env`.**

   ```bash
   cp tools/inbox/env.example tools/inbox/.env
   ```

   Открыть `tools/inbox/.env`, заполнить `NC_USER` (логин в Nextcloud) и `NC_PASS`
   (тот самый пароль приложения). Файл добавлен в `.gitignore` — в репозиторий не уедет.

3. **Сказать агенту «настрой ящик».** Он выполнит:

   ```bash
   bash tools/inbox/inbox.sh check   # проверить доступ
   bash tools/inbox/inbox.sh init    # создать папку и шаблоны
   ```

После этого в облаке появится папка `Antarus`:

```
Antarus/
    README.md      ← что куда класть
    TICKETS.md     ← очередь тикетов на следующий патч
    RUSTDESK.md    ← реквизиты удалённого доступа
    files/         ← скриншоты, логи, конфиги
```

Дальше всё делается мышью в браузере или в клиенте Nextcloud: открыть `TICKETS.md`, дописать тикет,
перетащить скриншот в `files/`. Ничего коммитить не нужно.

## Команды агента

```bash
bash tools/inbox/inbox.sh check              # доступ и наличие ящика
bash tools/inbox/inbox.sh tickets            # показать очередь
bash tools/inbox/inbox.sh pull               # скачать весь ящик в .inbox/
bash tools/inbox/inbox.sh put release.msi    # положить файл обратно в files/
```

`pull` кладёт зеркало в `.inbox/` в корне репозитория — папка в `.gitignore`, чужие скриншоты и
пароли в историю не попадут.

## Если доступ ко всему облаку давать не хочется

В `.env` вместо `NC_USER`/`NC_PASS` можно заполнить `NC_SHARE` — токен публичной ссылки на одну
папку (хвост адреса после `/s/`). Тогда агент видит только её. Для `put` в свойствах ссылки нужно
включить «Разрешить редактирование», иначе доступ будет только на чтение.

## Что делать, когда сеанс закончен

Пароль приложения отзывается в том же разделе «Устройства и сеансы» крестиком напротив
`antarus-agent`. Одноразовый пароль RustDesk после сеанса лучше сменить — он остаётся лежать
в `RUSTDESK.md` в облаке.
