Segnetics Loader v2.8.9

Назначение:
- загрузка ELF-бинарника в /projects на ПЛК;
- загрузка LFS через штатные скрипты ПЛК без запуска SMLogix.exe;
- сборка PSL -> LFS через установленный SMLogix;
- сборка ZOP-пакета из LFS/PSL и ELF.

Запуск:
- SegneticsLoader.exe

Требования:
- Windows x64;
- установленный .NET 8 Desktop Runtime x64;
- для PSL -> LFS и загрузки LFS нужен установленный SMLogix с 7za.exe;
- доступ к ПЛК по SSH/SFTP.
