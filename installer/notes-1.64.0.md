Привёл паспорта к тому, что и просил с самого начала: не отдельная подсистема с хранимыми записями и двумя пунктами меню, а один генератор по шаблону.

ПАСПОРТ — ЭФЕМЕРНЫЙ, ПО ШАБЛОНУ

Убрал всё лишнее, что вокруг паспорта наросло. Больше нет страницы «Паспорта шкафов» со списком сохранённых паспортов, нет привязки паспорта к типу и подтипу шкафа, нет отметки «паспорт» на карточках прошивок и счётчика в поиске. Паспорта больше не таскаются между машинами при синхронизации.

Остался один функционал — «Сформировать паспорт». Нажимаешь кнопку, выбираешь шаблон, вписываешь название шкафа — программа подставляет название в копию шаблона и показывает готовый лист. Дальше «Редактировать» или «Печать». Ничего никуда не сохраняется: сформировал, напечатал — и всё. Нужен снова — формируется заново.

Точка входа теперь ровно одна: «Сформировать паспорт» в боковом меню. Второй, дублирующей кнопки больше нет.

ШАБЛОНЫ — ПРОСТО ФАЙЛЫ

Шаблоны паспортов лежат файлами в общей папке на диске, ровно как наклейки, — никаких записей в базе. Загрузить шаблон можно в Настройки — Печать, кнопкой «Загрузить…». Можно держать несколько шаблонов и разные редакции: они просто лежат файлами рядом.

Слово «бланк» из программы убрал — везде теперь «шаблон».

Подстановка длинного названия без сбоя вёрстки и двусторонняя печать с переворотом по короткой стороне работают как раньше.

НАКЛЕЙКИ

Добавил удаление: если загрузил не тот файл, теперь его можно убрать из общей папки прямо из окна — с подтверждением. Кнопку «Открыть» убрал, вместо неё файл открывается двойным кликом по строке. Кнопку «Закрыть» убрал — у окна есть крестик. Убрал и непонятный столбец «Раздел»: окно стало простым списком файлов с кнопками «Загрузить…», «Удалить» и «Открыть папку».
